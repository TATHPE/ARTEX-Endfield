本机检查

发现的问题

    按顺序试这几步

    1. 缺 Visual C++ 运行库（最常见）：安装 Microsoft Visual C++ 2015-2022 Redistributable (x64)，装完重启电脑再打开 ARTEX。
      便携 PostgreSQL 依赖它；干净系统上缺了它 postgres.exe 会直接加载失败。
    2. 确认安装目录是纯英文且可写（例如 D:\ARTEX）。
      含中文/空格的路径会让 PostgreSQL 的 initdb 失败。
    3. 端口被占：本版会自动改用空闲端口，无需手动处理；若仍失败，关掉占用 5433 / 8787 / 8788 的软件后点下面的“重试”。
    4. 杀毒软件误报：把整个安装目录加入白名单（重点 resources\pgsql\bin\postgres.exe 与 resources\artex\artex.exe）。
